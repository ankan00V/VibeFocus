# Testing Instructions for Safari

1. Open the app in Safari.
2. Select a timer duration (e.g. 1 minute for quick testing).
3. Click "Start". 
4. Check if the PiP icon allows you to enter PiP mode successfully (it should now properly use the user gesture token).
5. Watch the leaves fall - they should now fall exactly one by one, spaced out mathematically based on the total time, with their original floating physics.
6. Check that when the timer reaches 0, exactly 0 leaves remain attached to the tree.
